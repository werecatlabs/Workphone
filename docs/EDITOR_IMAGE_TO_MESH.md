# Image to Mesh in the Editor

Open **Window > Image to Mesh** to generate a full 3D object from a PNG or JPEG.
Choose **Meshy** or **TRELLIS 2 (fal.ai)** in **Generation provider**. The Editor
sends the selected image to that provider, downloads a GLB, and requests import
through the normal project asset pipeline. TRELLIS 2 runs on fal.ai's hosted
service; no local model installation or GPU server is needed.

## Setup

1. Create a key for the provider you want to use:
   - Meshy: follow the [Meshy authentication guide](https://docs.meshy.ai/en/api/authentication).
     A paid API-capable plan and sufficient credits are required.
   - TRELLIS 2: create a fal.ai key using the
     [fal.ai API setup](https://fal.ai/models/fal-ai/trellis-2/api).
     Generations use your fal.ai account balance.
2. In **File > Settings > Editor**, open **Meshy** or **TRELLIS 2 (fal.ai)**,
   enter the key in the masked field, and click **Save Meshy Key** or
   **Save fal.ai Key** respectively.
3. Open or create a saved project with a writable asset catalog.

Meshy, fal.ai, and OpenAI keys are separate. On Windows each is saved separately
in Windows Credential Manager for the current user, outside project files and
settings exports. New requests use saved keys immediately. The saved value is
never displayed; enter a new value to replace it or use the provider's remove
button. `MESHY_API_KEY` and `FAL_KEY` are optional fallbacks when the corresponding
Editor key is absent. Non-Editor clients use environment variables only.

## Generate a mesh

1. Choose the generation provider, then click **Browse Image...** or enter an image path. Relative paths refer to the
   current project. Images generated by **Text to Image** can be selected here.
2. Choose an asset name and a target count (10,000, 30,000, or 100,000).
   Meshy uses a polygon target and allows textures to be disabled. TRELLIS 2 uses
   a vertex decimation target, always generates textures, and offers resolutions
   512, 1024 (default), and 1536. These counts are generation targets, not guarantees.
3. Click **Generate Mesh**. This uploads the image to the selected provider and
   uses that provider's credits. Provider and options are locked during the request.
4. Continue editing while the panel displays the remote task's stage and ID.
   Meshy supplies percentage progress; fal.ai supplies queue/processing stages.
5. The GLB is saved under `Assets/Generated` using an unused filename. The Editor
   requests import; once import finishes, drag the asset from Project Assets into
   the scene using the normal mesh workflow.

**Discard Pending Mesh** stops local polling/downloading and prevents saving the
result. It does not cancel or delete the remote task, which may continue and
use credits. Project/catalog changes also discard the pending local result.
Closing the Editor signals cancellation and waits for the current network
operation to return before tearing down the worker.

Failures do not automatically start another paid task. For missing/invalid keys,
update Editor settings. For insufficient credits or a plan restriction, check
the selected provider's account. For rate limits, wait before trying again. If a task ID is
shown after an error or local discard, check that task in the provider's dashboard before generating
again; it may already have completed remotely.

## Supported input and output

- Input: PNG/JPEG, at least 32 pixels on each side, at most 20 MiB. The service
  also enforces its image-dimension and content requirements.
- Generation: Meshy `meshy-7.1` or fal.ai `fal-ai/trellis-2`, one GLB result.
- Output: self-contained GLB 2.0 with triangle geometry and embedded textures.
  External file references and malformed geometry are rejected before saving.
  Embedded WebP textures from TRELLIS 2 are decoded through the engine's image loader.
- Bounds: 128 MiB GLB download limit and bounded polling/HTTP timeouts.
- Platforms: HTTPS generation and persistent key storage are implemented for
  Windows. Unsupported platforms return an explanatory error.

The panel reports **import requested**, since project import runs asynchronously.
A saved source GLB is retained if import fails, so it can be imported again from
Project Assets. The tool does not automatically modify the scene.

Build `MeshyClientTests`, `Trellis2ClientTests`, `MeshyCredentialTests`,
`Trellis2CredentialTests`, `ImageToMeshAssetTests`, `ImGuiViewportInputTests`, `FreeImageWebPTests`,
`TextToImageAssetTests`, and `Editor`. Run CTests `WPAI.image_to_mesh`,
`WPAI.trellis2_image_to_mesh`, `WPAI.meshy_credentials`, `WPAI.trellis2_credentials`,
`WPImGui.viewport_input`, `WPGraphics.webp_container_padding`, `WPEditor.image_to_mesh_assets`, and
`WPEditor.text_to_image_assets`, plus `Tests/lua/ProjectSettingsTests.lua` with
`luavm.exe`. The HTTP tests use mock responses; credential tests use disposable
targets. They do not access personal keys or create paid tasks.
