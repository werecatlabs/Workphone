Implemented
- DX11 Editor scene texture refreshes at up to 15 Hz after 0.5 seconds idle.
  Input, camera/projection/target changes restore full-rate refresh immediately.
  Play, realtime preview, active animation previews, held scene tools/gizmos,
  and paused debugger redraw requests bypass idle throttling.
  Periodic refresh remains because terrain/assets do not all expose revisions.
- Typed immutable pipeline settings are cached until relevant settings change.
  Native frame preparation no longer builds/reads the full property collection.
- Validated native culling reuse preserves a separate unsorted, unoccluded
  baseline. Camera, policy, scene membership, mesh, object and ancestor changes
  invalidate it. Each consuming view owns its index array; material bindings
  are still captured fresh. Cache is cleared before native scene teardown.
- SAT corner-relative coordinates and tolerance invariants are computed once
  per candidate, preserving the original arithmetic order.
- Inspector property groups take one owned snapshot and group category rows
  once, preserving nested metadata, ordering, filtering and fresh edits.

Headless culling benchmark
Command:
  WorkphoneGraphicsSceneJobTests.exe --cull-benchmark <output.csv> 10000 0.25 1 7 123 0 0 reuse
Seven alternating pairs, 10,000 unchanged objects, 1,000 main-visible objects,
zero workers, 0.25-second warmup and 1-second measurement windows per mode.
Median of the seven window lifecycle medians:
  Fresh main/shadow batch: 4.3141 ms (range 4.1844-4.51855 ms).
  Validated reuse:         0.2478 ms (range 0.2086-0.29485 ms).
  Reduction: 94.26%; isolated speedup: 17.41x.
Independent view-index allocation and retirement are included. Main/shadow
object/world-matrix parity was checked outside the timed intervals. Reuse
performed zero transform multiplies. Both modes include the SAT improvement.
This excludes material capture, GPU rendering, scene texture refresh and Present;
it does not measure whole-Editor performance or FPS.
Evidence: cull-reuse.csv, cull-reuse-summary.json, cull-reuse.log.
